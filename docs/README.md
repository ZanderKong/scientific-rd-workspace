# Documentation Map

从 [`handoff/CURRENT_STATE.md`](handoff/CURRENT_STATE.md) 开始。它是唯一当前状态文件。

## Current

`current/` 保存当前产品、数据模型、UI、API、Agent、MCP 和依赖契约。

## History

`history/` 保存当前 Research Object Graph 架构的已完成执行计划、交接及审计证据。文件中的 commit、验证结果和时间是历史事实，不等于今天的运行状态。

## Archive

`archive/` 保存旧 Phase、旧 AI/Literature/Evidence/Evaluation/Compare runtime、旧 Starter 规划和旧审计。它们用于追溯，不是 Agent 的实现指令。

## Screenshots

`assets/ui/current/` 只放当前界面截图；`assets/ui/archive/` 放旧界面截图。当前基线截图为 [`samples-zh-CN.png`](assets/ui/current/samples-zh-CN.png)，同时作为 Web 分享图的 `web/public/scientific-rd-workspace.png`。
