# Agent Interface v1.5

Agents provide natural-language interpretation and orchestration. The workspace owns canonical validation, scope, hashes, revisions, lineage synchronization and transactions.

Read through the v1.5 MCP tools/resources or REST DTOs. Search before creating a Research Object, Process Definition, Data, View or Claim. External writes are proposal-first ChangeSets and must carry project scope; reviewed application is explicit.

Do not invent old object kinds, ownership relations, payload endpoints or comparison/execution endpoints. Do not infer `subject` or `derived_from`; create/update Process Execution bindings and let the canonical service synchronize them.
